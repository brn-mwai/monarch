\subsection*{Changes since your last review}

\begin{enumerate}[leftmargin=*]
\item \textbf{Baselines (Chapter 5).} On the same 400 items and label, TF-IDF with logistic
regression reaches AUC $0.9758$ against the index's $0.6274$; VADER sentiment does not clear
chance. The thesis states that the index is a field observable, not a competitive classifier.
\item \textbf{Leave-one-source-out (Chapter 5).} Not computable: every source dataset carries
exactly one class. The 150 ISOT items, the one source with both classes, are used instead;
TF-IDF still reaches $0.9724$ there.
\item \textbf{The outrage result (Chapters 5 and 6).} High outrage raises both networks
almost equally ($d = +0.507$ and $+0.491$), so its flat index is a symmetric response, not an
absent one. The earlier argument that this argues against pure source detection is withdrawn.
\item \textbf{Sign reversals (Chapter 6).} 51 of 400 items reverse between sessions; the
measured session noise predicts $55.3$, 95\% interval $[44, 67]$. No per-item claim is made.
\item \textbf{Citations and wording.} Every dataset, model and atlas is now cited where it is
used. The bound $\alpha \ge h_c(\beta J)/\Delta X$ is stated as a result for the all-to-all
mean-field model, since network structure lowers $h_c$.
\end{enumerate}
