*Measuring the External Field: A Cortical-Proxy Content Observable and the Mean-Field Bound on Media-Driven Opinion Change*

Brian Mwai (1050555), B.Sc. Physics
Supervisor: Dr. Songa Mutambi

*Abstract*
Physicists model opinion formation with the Ising model, the same mathematics that describes how magnetic spins in a metal align. In its mean-field version, each person holds one of two opinions, is pulled toward the majority by a coupling J, and media acts as an external field h pushing everyone the same way. Studies choose the value of h by hand; it is never measured. This project asks whether it can be measured from the content itself.

Each news article was converted to speech and passed through TRIBE v2, a published AI model from Meta that predicts the brain's response. The project compares predicted activity in regions linked to emotion with regions linked to careful reasoning, giving one number X per article. No person was scanned; every value is a model prediction.

Four hundred articles in four groups (fear-driven, outrage, clickbait and neutral) were measured twice. The groups differ clearly (η² = 0.107, p < 10⁻⁸), led by fear-driven articles, and the result repeated on the second run. Each group came from a different source, however, so the difference cannot be credited to writing style alone, and a simple word-counting method sorted manipulative from neutral articles better than this measure. The measure is therefore offered as a physical quantity, not a manipulation detector.

Writing the field as h = αX, the strength α with which content pushes opinion could not be pinned down from the data, so no value is claimed. Instead, the thesis derives a condition that needs no fitted value: in this model, media can flip a population's majority only if α ≥ h_c(βJ)/ΔX, where h_c is the critical field and ΔX the spread of the measure. With the measured ΔX = 0.124, this requires α ≥ 4.29 at βJ = 2, a minimum any future media-influence model of this kind must meet.
